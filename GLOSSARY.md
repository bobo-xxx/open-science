# Open Science

Open Science manages research projects, conversations, and the work performed on their behalf.

## Language

**External Host**:
An application such as Codex that invokes Open Science on behalf of a user.

**Internal Agent Framework**:
The framework Open Science selects to execute a conversation turn.

**Session**:
A project conversation with persistent messages and settings that can be used for successive turns.

**Submission**:
The durable receipt for a request to start a Run.

**Run**:
The execution record for one task request in a Session.

**Compute Job**:
A tracked execution on a configured Compute Host, with its own state and results.

**Permission Profile**:
The selected policy for how Open Science handles a Session's tool permission requests.

**Grant**:
An authorization that applies to matching operations within its approved scope.

**Reviewer**:
The Open Science agent that assesses a turn's research work and produces a report.

**Auto-review**:
A Session setting to run the Reviewer automatically on eligible completed turns.
